# QFabric manuscript

The manuscript is an IEEE-style, venue-neutral draft backed by the audited
Stage 11 artifact. Quantitative plot and table inputs are generated from the
evaluation JSON rather than copied by hand.

Build from this directory with:

    make

The output is qfabric-paper.pdf. To replace the testbed placeholder, add a
landscape photograph at paper/figures/testbed.jpg and rebuild. The photograph
should show the UNO Q, its USB connection, and the host computer without
revealing serial numbers, screens, or private network details.

Before submission, replace the anonymous author block, select the target
venue's template, add the repository release DOI if one is minted, and run a
final bibliography and claim audit.
